# Electricity Bill Management System (EBMS)

Electricity Bill Management System is a web-based project designed to calculate electricity bills and manage customer meter readings.

## Features
- Customer Information
- Meter Reading Input
- Automatic Bill Calculation
- Live Bill Preview
- Printable Bill Summary

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Note
This project uses sample electricity tariff values for demonstration purposes only.
